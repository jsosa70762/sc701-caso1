# SC-701, Caso de estudio N°1 (Semana 7)

**Auditoría de un incidente en SistemaSoporte.** Actividad individual, en clase, de 60 minutos.

## Qué hacer, en este orden

1. **Su versión** es la letra que le asigne el profesor (A, B o C). Descargue **solo el PDF de su versión** de esta carpeta (`Caso1-VersionA.pdf`, `Caso1-VersionB.pdf` o `Caso1-VersionC.pdf`). La versión en `.md` es la misma, por si prefiere abrirla en un editor.
2. Cuando tenga el archivo, **apague el Wi-Fi o active el modo avión**. El profesor lo verificará.
3. Lea el caso y responda **en un documento Word o PDF** llamado `Caso1_Carnet_Apellido`.
4. Al terminar el tiempo, con el profesor presente, vuelva a conectarse y **suba su archivo** en el espacio **Caso de estudio N°1** de la plataforma.

## Reglas

- Es **individual**. No se permite hablar con compañeros.
- **No se permite inteligencia artificial, ni celular, ni internet** mientras responde.
- Material permitido: la presentación de la Semana 6 y el código del proyecto de clase, que ya deben tener descargados.
- Se califica únicamente la versión que le fue asignada.
- No hay prórroga.
